Plan: 事前学習の学習曲線（SAFE-GPT / RFFMG-T5）

Date: 2026-07-08 | Status: approved

概要

SAFE-GPT と RFFMG-T5 の学習過程を可視化するため、loss（縦軸）vs steps（横軸）の学習曲線を描く。

前提: ダウンロードした「pretrained」モデルには学習ログが無く、ログが残るのはユーザーが実行した学習run（wandb オフライン）のみ。よって本タスクの「事前学習の学習曲線」= これら学習runの曲線として描く。両モデルとも wandb に train/loss / eval/loss / train/global_step を記録済み（eval行にも train/global_step が入る）。損失は wandb.sdk.internal.datastore で run-*.wandb から抽出可能（検証済み）。run名の旧称: dummy=rffmg、our_slice=rc_cms。history item のキーは item.key or '/'.join(item.nested_key)。

ユーザー確定事項

  • フラグメント手法: rc_cms + brics 両方
  • T5の種別: trained + from_scratch 両方（SAFEは from_scratch run が無く trained のみ）
  • 図の構成: モデルごとに別ファイル
  • 損失: train + eval loss 両方を1枚に重ねる

出力（合計6枚、figures/learning_curves/ 配下）

  • rffmg_t5_trained_brics.png
  • rffmg_t5_trained_rc_cms.png
  • rffmg_t5_from_scratch_brics.png
  • rffmg_t5_from_scratch_rc_cms.png
  • safe_gpt_brics.png
  • safe_gpt_rc_cms.png

実装計画

  1. Step 1: wandb import を追加

    対象ファイル: src/figure.py（先頭サードパーティimport群、13行目 from rdkit import Chem 付近）

    変更内容: from wandb.sdk.internal import datastore と from wandb.proto import wandb_internal_pb2 as wandb_pb を追加。

    依存関係: なし

  2. Step 2: wandbからloss履歴を抽出する関数を追加

    対象ファイル: src/figure.py（frag_num_analyze 直後、if __name__ の直前）

    変更内容: read_wandb_loss_history(run_path: str) -> pd.DataFrame を追加。datastore.DataStore().open_for_scan で走査し history レコードを収集。キーは item.key or '/'.join(item.nested_key)、値は float(value_json)。train/global_step を step、train/loss/eval/loss を各行から拾う。返り値カラム: step(int), train_loss(float,NaN可), eval_loss(float,NaN可)、step昇順。型ヒント・Google style docstring・カラム名明記。

    依存関係: Step 1 の後

  3. Step 3: 学習曲線を描画・保存する関数を追加

    対象ファイル: src/figure.py（Step 2 の関数の直後）

    変更内容: plot_learning_curve(history: pd.DataFrame, save_path: str, title: str) -> None を追加。train_loss/eval_loss を dropna() して step(x) vs loss(y) の2本を描画（凡例つき、train実線/eval区別）。軸ラベル Steps/Loss、title設定、os.makedirs→savefig→plt.close()。eval空でも描けるようガード。

    依存関係: Step 2 の後

  4. Step 4: 実行ブロックをファイル末尾に追加

    対象ファイル: src/figure.py（if __name__ == "__main__": 内の最終ブロックとして末尾）

    変更内容: 新規 if 1: ブロックを追加。採用run表の対応辞書（出力名→wandbディレクトリ相対パス）を定義し、out_dir = f'{fd}/figures/learning_curves'、各runを glob(f'{fd}/{run_dir}/run-*.wandb')[0] で解決→read_wandb_loss_history→plot_learning_curve。fd は既存の __main__ 冒頭定義を流用。

    依存関係: Step 3 の後

  5. Step 5: 既存アクティブブロックを無効化

    対象ファイル: src/figure.py（205行目 if 1:）

    変更内容: 205行目の if 1: を if 0: に戻し、新ブロックのみが実行されるようにする（単一ブロック運用の踏襲）。

    依存関係: Step 4 の後

検証

  1. 実行: conda run -n safe python src/figure.py
  2. ls -l figures/learning_curves/ で6枚のPNG生成を確認
  3. 各PNGを開き、横軸=Steps・縦軸=Loss で train/eval 2本が描かれ、step範囲が採用run表と整合していることを目視確認
  4. 任意: read_wandb_loss_history を1runで単体実行し、末尾 eval_loss が既知値（rc_cms SAFE ≈ 0.477、trained rc_cms T5 ≈ 0.149）に近いことを確認
