Plan: run_safe.sh に学習モード（from_scratch / finetune）切替を追加

Date: 2026-07-08 | Status: pending-approval

概要

src/train_model/run_safe.sh は現状 --model_path を渡さず常にゼロ学習になり、 出力先も models/safe_gpt/trained/（規約では trained=ファインチューニング）固定で両立できない。 MODE 変数（from_scratch / finetune）を導入し bash の if/else で切り替える。

MODE--model_path--output_dir
finetunemodels/safe_gpt/pretrained を付与（重み継承）models/safe_gpt/trained/safe/${FRAG_NAME}/
from_scratch付与しない（ランダム初期化）models/safe_gpt/from_scratch/safe/${FRAG_NAME}/

--config / --tokenizer は両モードとも pretrained のものを使用（構造・語彙を揃え比較を公平に）。 その他のハイパーパラメータは現状維持。

実装計画

  1. Step 1: run_safe.sh にモード切替を実装

    対象ファイル: src/train_model/run_safe.sh

    変更内容: MODE 変数と PRETRAINED_DIR を追加。 if/elif/else で MODEL_PATH_ARG と OUTPUT_DIR を切替（未知の MODE は stderr にエラー出力して exit 1）。safe-train 呼び出しで ${MODEL_PATH_ARG}（空なら無視）と --output_dir ${OUTPUT_DIR}、 --config/--tokenizer は ${PRETRAINED_DIR} 配下を使用。他の引数は現状維持。

    依存関係: なし

実装後の run_safe.sh（想定内容）

#!/usr/bin/env bash
export CUDA_VISIBLE_DEVICES=0

# conda setup
source ~/miniconda3/etc/profile.d/conda.sh
conda activate safe

FRAG_NAME="rc_cms"          # "brics" or "rc_cms"
MODE="finetune"            # "finetune" or "from_scratch"

PRETRAINED_DIR="models/safe_gpt/pretrained"

if [ "$MODE" = "finetune" ]; then
    MODEL_PATH_ARG="--model_path ${PRETRAINED_DIR}"
    OUTPUT_DIR="models/safe_gpt/trained/safe/${FRAG_NAME}/"
elif [ "$MODE" = "from_scratch" ]; then
    MODEL_PATH_ARG=""
    OUTPUT_DIR="models/safe_gpt/from_scratch/safe/${FRAG_NAME}/"
else
    echo "Unknown MODE: ${MODE} (use 'finetune' or 'from_scratch')" >&2
    exit 1
fi

safe-train \
${MODEL_PATH_ARG} \
--config ${PRETRAINED_DIR}/config.json \
--tokenizer ${PRETRAINED_DIR}/tokenizer.json \
--dataset data/safe/${FRAG_NAME}/normal \
--output_dir ${OUTPUT_DIR} \
--text_column full_safe \
--num_train_epochs 50 \
--learning_rate 1e-4 \
--warmup_steps 10000 \
--do_train \
--do_eval \
--eval_strategy steps \
--per_device_train_batch_size 32 \
--eval_steps 5000 \
--save_strategy steps \
--save_steps 5000 \
--save_total_limit 5 \
--load_best_model_at_end

  • 既定は MODE="finetune"（元の意図＝ファインチューニングと解釈）。ゼロ学習時は手で from_scratch に変更。
  • 空の ${MODEL_PATH_ARG} は行継続と併用しても問題なく無視される。
  • 対象は run_safe.sh のみ。生成側（gen_safe.py / gen_safe_denovo.py）の from_scratch/ モデル読込パス変更は含めない（必要なら別途）。
