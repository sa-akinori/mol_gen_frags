Plan: 学習スクリプトの出力構造を新レイアウトに移行し、wandb を識別可能に保存

Date: 2026-07-08 | Status: pending-approval

概要

学習の保存先を新レイアウト models/{gpt|t5chem}/{safe|rffmg}/{mode}/{slice}/ に移行し、 wandb の run を「どのモデル/表現/モード/slice か」で識別・フィルタできるようにする。 MODE の値も dir 名と揃え finetuning / from_scratch に統一（従来の finetune から改名）。

modelreprmode出力先
gptsafefinetuningmodels/gpt/safe/finetuning/${FRAG_NAME}/
gptsafefrom_scratchmodels/gpt/safe/from_scratch/${FRAG_NAME}/
t5chemrffmgfinetuningmodels/t5chem/rffmg/finetuning/${FRAG_NAME}/
t5chemrffmgfrom_scratchmodels/t5chem/rffmg/from_scratch/${FRAG_NAME}/

pretrained ソースは本タスクでは移動せず、models/safe_gpt/pretrained / models/t5chem/pretrained をそのまま参照（実ファイル移動・生成側パス更新は別途）。

wandb マッピング

項目safe (gpt)t5chem
projectgpt_safe（--wandb_project）t5chem_rffmg（env + パッケージ setdefault 化）
識別名WANDB_RUN_GROUP=${MODE}_${FRAG_NAME}（run名は uuid 固定のため group）--run_name "${MODE}_${FRAG_NAME}"
tagsgpt,safe,${MODE},${FRAG_NAME}t5chem,rffmg,${MODE},${FRAG_NAME}

実装計画

  1. Step 1: run_safe.sh を新構造 + wandb 対応に更新

    対象ファイル: src/train_model/run_safe.sh

    変更内容: MODE を finetuning/from_scratch に改名。 OUTPUT_DIR を models/gpt/safe/{mode}/${FRAG_NAME}/ に。 PRETRAINED_DIR="models/safe_gpt/pretrained" は据え置き。 分岐後に export WANDB_RUN_GROUP="${MODE}_${FRAG_NAME}" と export WANDB_TAGS="gpt,safe,${MODE},${FRAG_NAME}" を追加。 safe-train に --wandb_project gpt_safe を追加。他は現状維持。

    依存関係: なし

  2. Step 2: run_t5chem.sh を新構造 + wandb 対応に更新

    対象ファイル: src/train_model/run_t5chem.sh

    変更内容: MODE を finetuning/from_scratch に改名。 OUTPUT_DIR を models/t5chem/rffmg/{mode}/${FRAG_NAME} に。 分岐後に export WANDB_PROJECT="t5chem_rffmg" と export WANDB_TAGS="t5chem,rffmg,${MODE},${FRAG_NAME}" を追加。 t5chem train に --run_name "${MODE}_${FRAG_NAME}" を追加。他は現状維持。

    依存関係: なし

  3. Step 3: t5chem run_trainer.py（site-packages）を wandb 有効化 + project を env 尊重に

    対象ファイル: /home/sato/miniconda3/envs/t5chem/lib/python3.12/site-packages/t5chem/run_trainer.py

    変更内容: 114行目 os.environ["WANDB_PROJECT"]="T5Chem" → os.environ.setdefault("WANDB_PROJECT", "T5Chem")。 265行目 report_to="none", → report_to="wandb",。

    依存関係: Step 2 の後

    注意: site-packages（リポジトリ外）の編集で t5chem 再インストール時に失われる。 README_ja への手順追記を推奨（本計画では任意）。

確認事項

  • 既定は両スクリプトとも MODE="finetuning", FRAG_NAME="rc_cms"。
  • pretrained ソースは旧パスのまま。出力のみ新構造。生成側スクリプトの新パス対応は本計画外。
  • 既存モデルディレクトリの物理移動は本計画外（別途）。
  • safe-train は run 名を safe-model-<uuid> で固定するため、safe の識別は project+group+tags+config に依存。
