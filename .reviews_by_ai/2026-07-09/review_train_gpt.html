[C002] 学習率などのパラメータが safe-gpt と一致（max_length のみ異なってよい）

結果: PARTIAL | 確信度: HIGH

確認箇所: train_gpt.py:106-121, 156-171 vs run_safe.sh:40-51

判定理由: 主要 HP は全一致（epochs=50, lr=1e-4, warmup=10000, train_batch=32, eval/save steps=5000, save_total_limit=5, load_best_model_at_end, eval/save_strategy=steps）。差分1点: per_device_eval_batch_size=32 を明示（safe は未指定で既定 8）。評価スループットのみに影響し学習結果には無影響。

実トレース確認（改変後 safe 現物）: safe の --config は AutoConfig.from_pretrained のモデル config で学習HP config ではない。per_device_eval_batch_size の代入も無し → 実効 8 で確定（config 調整ではない）。

備考: 厳密一致を求めるなら eval batch を未指定に。実運用は許容範囲、ユーザー判断。

[C003] "A>>B" のうち "A>>" を入力、"B" のみ出力し損失計算・学習

結果: PASS | 確信度: HIGH

確認箇所: train_gpt.py:53-58（RFFMGDataset）

判定理由: input_ids=[bos]+prompt+target+[eos]、labels=[-100]*(1+len(prompt))+target+[eos]。位置一致・オフバイワン無し。プロンプト（<bos> source ">>"）は -100 マスク、loss は target と eos のみ。

備考（縁ケース）: 1+len(prompt) >= max_length の超過例は labels 全 -100（信号ゼロ・eos 欠落）になり得る。max_length=256 にデータ長が収まれば実害なし。

[C004] 再現性が担保されている

結果: PARTIAL | 確信度: HIGH

確認箇所: train_gpt.py:20, 134, 169 vs src/func/utility.py:26-42

判定理由: transformers.set_seed + TrainingArguments(seed=...) でシード固定・データシャッフル決定性は確保。ただしプロジェクト標準 func.utility.set_seed（cudnn.deterministic / use_deterministic_algorithms / CUBLAS_WORKSPACE_CONFIG / PYTHONHASHSEED）ではないため GPU ビット決定性は未保証。

備考: 完全決定化を要求するか要確認（use_deterministic_algorithms(True) は例外/速度低下の可能性）。【ユーザー承認済み】 → func.utility.set_seed 化を実施（Step 2 確定）。

[C005] 学習過程が wandb の適切なフォルダに保存（モデルも保存）

結果: PASS | 確信度: HIGH

確認箇所: train_gpt.py:131, 170, 182-184 vs run_rffmg.sh:23-25

[C006] early_stopping の設定が入っている（詳細は safe-gpt や t5chem と同じ） ← 最重要

結果: PARTIAL | 確信度: HIGH

確認箇所: train_gpt.py:173-180 / safe trainer/cli.py:340 / t5chem run_trainer.py:280

判定理由（grep 事実）:

  • train_gpt.py: Trainer(...) に callbacks 無し → EarlyStoppingCallback 無し（load_best_model_at_end のみ）。
  • safe-gpt（最も近い基準）: SAFETrainer に callbacks 無し、trainer 配下に early stopping 実装 無し。
  • t5chem: callbacks=[EarlyStoppingCallback(early_stopping_patience=15)] if do_eval else []、metric_for_best_model="eval_loss" 明示 → 有り。

→ train_gpt.py の「early stopping 無し」は safe-gpt と一致・t5chem と不一致。基準が割れている。

改変後 safe 現物での再確認: ユーザー改変済み safe/ パッケージ全体を再 grep → early stopping は どこにも無し（後付けも無し）を確定。

備考（最重要・要確認）: 「safe-gpt 準拠で不要」か「t5chem 準拠で patience=15 導入」か方針判断。導入時は EarlyStoppingCallback ＋ metric_for_best_model="eval_loss" が必要。
